# Weather-Forecasting-using-LSTM
 Weather Forecasting Model : Built a time-series LSTM model to forecast temperature,
humidity, and rainfall using historical weather data. Handled missing values, scaled features, and ex
tracted temporal features, leveraging inputs like tempmax, tempmin, humidity, precipitation, windspeed,
and cloud cover. Achieved an RMSE of 1.9°C for temperature predictions on the test set
